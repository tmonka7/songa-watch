# Languages

The watch ships English and Japanese. Switching is immediate: changing the
language posts `WATCH_EV_LANG_CHANGED`, and `ui.c` rebuilds the current
screen so every label is recreated with the new string and the right font.

## How the tables work

`svc_i18n.h` declares a flat `i18n_id_t` enum. `svc_i18n.c` holds two
parallel tables written with designated initialisers:

```c
static const char *const s_en[STR_COUNT] = {
    [STR_BACK] = "Back",
    ...
};
```

Designated initialisers mean the tables cannot silently drift out of step
with the enum — a new `STR_*` that nobody fills in is `NULL`, and `i18n_in()`
falls back to English rather than rendering a blank label.
`tools/check_consistency.ps1` fails the check if any id is missing from
either table.

## The font constraint

LVGL bundles `lv_font_source_han_sans_sc_16_cjk`. It is **not** a complete
CJK face — it is a fixed subset of about 1373 glyphs, generated from a
specific `--symbols` list which is recorded in the header of the generated
`.c` file.

A character outside that subset renders as nothing on the device. There is
no compile error and no runtime warning. The only defence is to check, so:

```bash
pwsh -File tools/check_i18n_font.ps1
```

parses the font's own `--symbols` list, then scans every non-ASCII string
literal in `components/watch_svc`, `components/watch_ui` and `main` against
it. **Run this after editing any Japanese text.**

## Substitutions the subset forced

Ten kanji that the natural translation wanted are not in the font. Where
that happened, the wording was changed rather than the font:

| English | Natural Japanese | Missing glyph | What ships | Note |
| --- | --- | --- | --- | --- |
| Voltage | 電圧 | 圧 | 電位 | "Electric potential" — understood in a technical context |
| Warning | 警告 | 警 | 注意 | "Caution" — the ordinary word on a dashboard |
| Fuel Level | 燃料残量 | 燃 | ガソリン残量 | Katakana "gasoline" |
| Devices | 機器 | 器 | デバイス | Katakana loanword, standard in device UIs |
| Diagnostics | 診断 | 診 | チェック | "Check" |
| Coolant | 冷却水 | 却 | 水温 | "Water temperature" — what the PID actually reports |
| Intake temp | 吸気温度 | 吸 | インテーク温度 | Katakana "intake" |
| Enabled / Disabled | 有効 / 無効 | 効 | オン / オフ | "On"/"Off" |
| Time zone | タイムゾーン | ゾ | 時間帯 | The native term |
| Seconds | 秒 | 秒 | *(avoided)* | Durations use digits and `sec` |

None of these are wrong Japanese — they are the second-choice word where the
first was unavailable.

## Fonts by role

Latin and every numeral always come from Montserrat, at whatever size the
role calls for. Only translated *text* switches to the CJK face, and only at
its native 16 px — scaling a bitmap font produces mush.

That is why `ui_font_text()` returns Montserrat for `UI_FONT_HUGE` and
`UI_FONT_LARGE` even in Japanese: those roles are numeric by design (the
clock, headline values), so the big type looks identical in both languages.

## Adding a language

1. Add the value to `watch_lang_t` in `svc_settings.h`.
2. Add a table to `svc_i18n.c` and register it in `s_tables`.
3. Add a row to the list in `scr_language_create()`.
4. If the script needs glyphs Montserrat lacks, enable or generate a font
   and extend `ui_font_text()`.
5. Run both checker scripts.

## Replacing the subset font

To lift the glyph restriction, regenerate the font with a full character
set and swap it in:

```bash
npx lv_font_conv --font NotoSansJP-Regular.ttf \
  --range 0x20-0x7F --range 0x3000-0x30FF --range 0x4E00-0x9FFF \
  --size 16 --bpp 4 --format lvgl --no-compress \
  -o lv_font_jp_16.c
```

Then reference `lv_font_jp_16` from `ui_font_text()` and point
`tools/check_i18n_font.ps1` at the new file. Expect a few hundred kilobytes
of flash for the full JIS level-1 set — which is why the bundled subset is
the default.
